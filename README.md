# Pot-stand-

## Overview 

This is my hardware project of a simple plastic pot stand. first, I made design using CAD software. after completing the 3D model, I export the file but unfortunately, my 3D printer was broken. So, after I go to shop and I give order of my project. The final printed stand can be used to hold flower pots. This part is used to keep the flower pot above the surface.

----

## Why I made this project 

I face the problem with my flower pot. I wanted to make a simple and useful stand for it. I also wanted to learn convert CAD design into real hardware using a 3D printer. 

----

## Materials and tools

If you have 3D printer:
- 3D printer
- plastic filament
- CAD software
- computer

- sand paper ( for small finishing )

If you didn't have 3D printer:
- CAD software

- sand paper ( for small finishing )
-- you can go to shop and give order of that

----

## Design process 

first I study the shape of the real pot stand and make a simple design in CAD software. I made the round base. after make the three legs that support the stand to stood. after checking the size and shape export the file. 

----

## 3D printing ( if you have 3D printer )

~ After the CAD design was ready. Put the file into the 3D printer software and started printing. The printer made the stand layer by layer using plastic filament. 

~ After printing was finished. I removed the extra support material and clean the printed part. 

----

## How I built it 

1. First, I planned the pot stand shape.
2. I made the 3D design in the CAD software.
3. I checked the size of the model.
4. I exported the model for 3D printing ( if you have 3D printer ).
5. Updated they stand using plastic filament.
6. I remove the extra material which is printed with the plastic pot.
7. After I place there flower pot on it.
8. I check the stability and size and I found that it is perfect.

----

## Testing 

I tested The stand using a flower pot stand on it. I checked the pot is standing properly understand easily handle the weight.
